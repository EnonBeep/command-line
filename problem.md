# Problem
    People are sometimes unorganized on their computers, which makes it difficult to find files. Sorting files by hand is time-consuming. A simple way to organize copies of files into separate folders based on file type would save time.

# Initial Requirment
    R1: The user specifies the folder to organize as a command-line argument.
    R2: The program recognizes each file's type by its file extension.
    R3: The program sorts files into categories: images, documents, videos, and other.
    R4: The program creates a separate folder for each category and copies each file into its matching folder.
    R5: The program never modifies or deletes the original files.
    R6: The program shows a helpful error message when the folder does not exist or cannot be accessed.
