# File Organizer

Copies the files in a folder into category subfolders — `images`, `documents`,
`videos`, and `other` — based on file extension. Original files are never
modified or deleted. Requires Python 3 (no other dependencies).

## Run

```
python organizer.py <folder>
```

## Test

```
python -m unittest -v
```

See `problem.md` for requirements and `spec.md` for how each is met.
